# HouseForge Studio

Photos of a house → structured house model (via Claude vision) → procedural 3D render and technical 2D floor plan, with furniture suggestions, interior redesign, empty-room view, whole-house mapping and exports (STL, OBJ, DXF, PDF, SVG, PNG, JSON).

- `artifact/houseforge.html` — single-page app published as a claude.ai artifact (uses the artifact `sample` capability for photo analysis and `downloads` for file export).
